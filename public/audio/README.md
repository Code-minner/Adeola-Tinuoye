# Discovery voice clips

Drop your recordings here. On click, the message shows and the matching clip plays.

| File | Line |
| --- | --- |
| `discover-01.mp3` | "Hey... you found this." |
| `discover-02.mp3` | "Okay, you're curious. I like that." |
| `discover-03.mp3` | "Thanks for stopping by. I hope you found something worth exploring." |

Keep each clip **1–3 seconds**, natural, quiet.

Until the files exist, the browser speech voice is used so sound still works on click.
Audio never starts on scroll — only after a click/tap.
